# Plans — the build record

These are the working documents the demo was built from, between August and September 2026,
kept as a record rather than as instructions. They are dated, they speak of "before the
conference", and later decisions sometimes reverse earlier ones; each file's own progress log
says when.

| File | What it is |
|---|---|
| `01-` … `07-` | One build spec per pattern: what was planned, what was built, the checkpoints that proved it, and what stayed open. The *As built* section is the part still worth reading |
| `03-opcua-analyzer-playbook.md` | How the OPC UA analyzer simulators were built, and how to build the next one |
| `00-master-plan.md` | The plan the seven patterns were built against |
| `demo-through-line.md` | The talk's narrative: why the patterns ran in the order they did on stage |
| `00-status.md`, `00-next-step.md`, `00-post-07.md`, `00-pre-07-cleanup.md`, `00-open-decisions-i3x.md` | Working notes from the build: status, next steps, open decisions |

For how the stack works today, read [`../00-architecture.md`](../00-architecture.md); to run it,
the [README](../../README.md) and [`../end-to-end-test.md`](../end-to-end-test.md).
