Simulator controls — not part of AP Connect

A real install has an instrument here. These fields stand in for what the filtrate was actually doing.

Free-run is a soak-test setting, not the talk. Leave it at 0: the catch-up demo depends on knowing exactly how many measurements should have arrived. Status override forces every subsequent measurement, including the free-running ones — CANCELED and FAILURE file a row with no haze values at all, which is the absent-not-zero checkpoint.
