Sample information

Scan the barcode or type the identifier printed by the sample valve on BR-201. The analyzer echoes whatever is entered here back on its result — it has no way to check it.

Run writes tags, not a method. The sample metadata above is written into OPCSystemCommands/ESMScheduleAnalysis/SampleInformation/*, then the ESMScheduleAnalysis bit is set. That is the whole vendor contract: 104 writable bits, zero OPC UA methods, and nothing atomic about the sequence. An Ignition tag write does exactly the same thing — and, unlike this screen, gets no answer back if the instrument declines.
